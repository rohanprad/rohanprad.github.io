Featured project

Which H&M lines should we mark down, and how deep?

Using 31.8 million real H&M transactions, I learnt from 19,668 past markdowns which discount depth actually works, comparing each against similar products still at full price.

30–50% cuts grew revenue by 45%; shallow cuts barely beat doing nothing. The dashboard flags 2,122 slow lines to mark down now.
